# WordTap 英语学习素材

品牌标语：**英语点读为学习而生**。功能短句：**点词查义 · 听读发音 · 文章跟打**。

服务于[英语学习入门教程](../../../docs/english-learning-guide.md)、README、博客与学习推广。原始操作取自 2026-10-21 本地构建预览，不冒充线上部署版本。

统一示例见 [example.txt](example.txt)：点击 learn 查义与看音标；第一句将 every 输入为 everx，展示应为 y／当前为 x 的反馈。
