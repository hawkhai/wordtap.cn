## 状态与证据

`pending` 为待审；`in_review` 为审核中；`edited_pending_recheck` 为修改待复核；`passed_unchanged` 为通读复核通过且无改动；`passed_edited` 为通读复核通过且已修改；`needs_source_check` 表示已审但仍有无法确认的问题。进度状态通过 start/recheck 明确登记，不能以扫描或候选生成冒充通过。

`ledger.tsv` 记录逐篇状态、哈希、修改数量和证据。`revisions/<course>/<id>.json` 保存审核前后显示字段、原资料哈希和定位、校勘项及明确的通读/复核确认。`events.jsonl` 以追加事件链记录审核结果，不因刷新台账删除证据。复审时旧修订以内容哈希归档到 history，保留原事件签名。空格数量统计横向空白差异区间；段落数量统计明确登记的合并、拆分、补入或类型调整操作；校勘数量统计有来源证据的校勘项。

纯排版不得改变非空白字符。校勘必须记录唯一定位的原文、修改后文字和来源证据；不依据词典猜测原资料。原资料本身的错误可以记录疑义，但不可冒充 OCR 错误。音标、缩写、网址、邮箱、小数、时间、连字符、占位符与音频时间戳保持完整。教学中的主语/谓语对齐空格不按普通散文清理。

## 工具

```powershell
npm run review:init:articles
npm run review:inspect:articles
python tools/review-articles.py start --path public/shuimu/lessons/beginner/013.json
python tools/review-articles.py recheck --path public/shuimu/lessons/beginner/013.json
python tools/review-articles.py record --path public/shuimu/lessons/phonetics/001.json --decision tmp/article-review/decision.json
npm run test:article-review
npm run verify:article-review
python tools/review-articles.py verify --require-complete
```

init 只建立或刷新清单，不审核文章；已审内容哈希变化时恢复待审。inspect 输出完整显示文本与保守的空格候选，不能自动通过。record 一次仅接受一个明确写出的审核决定，包含 sources（path、locator、checked）、notes、fullReadConfirmed、recheckConfirmed；可附逐块修改、合并、校勘证据与疑义。没有通读复核确认或前置内容不匹配就拒绝发布。恢复遗失导读可使用 prependBlocks，必须匹配原首块文字，新增块仅接受显示字段，并逐项提供原页面校勘证据；不允许插入 ID、时间戳或资源字段。

splitBlocks 可将已读的标题与正文拆为独立显示块，逐块校验前置文字，禁止引入资源、ID 或时间戳；拆分时继续验证非空白字符和来源校勘证据。

新概念非正文字幕（如听力提示）可使用 corrections 的 `field: sentences`、`index`、`language` 精确登记整句前后文字及证据。提问或标题字段的证据仅适用于对应角色；修改提示句不能借用问题修订的证据。正文校勘仍需同步 text/bodyText/bodyTextZh，时间戳和角色不得改变。

生成器只重放已登记修订，以显示字段前置哈希检测源变化，并检查幂等性。标题和字数等 manifest 摘要同步。原生成源与旧发布正文仅有空白差异时，逐篇比对后保存精确的 generator-baselines 前置哈希证明，不使用模糊匹配兜底。经原图逐项确认的块类型差异须在 blockTypeChanges 中登记索引、前后类型及证据；其余结构、文字、语言和元数据仍须完全一致。2020年7月四级参考答案页的旧整页标题误分类已据此记录，并在最终修订中拆分。大学英语已签名的正文不允许使用普通覆盖修订，必须先通过 record-college-english-review.py --revise-passed 追加其自身的复核修订事件，再用该课程生成器发布。最新复核事件必须与前一有效签名和正文哈希连续。发布数据偏离现有签名源稿时，可在验证完整签名链后恢复精确的已签名标题、正文与段落；不得借此引入未签名的新内容，恢复前后显示字段照常记入本台账。

新概念和研究生英语子模块已恢复到仓库锁定提交。研究生英语缺失的 6 个补充源从当前发布正文恢复，source-recovery.json 单独记录恢复前后哈希；恢复不代表本轮逐篇审核通过。临时生成统一使用 --output tmp/article-review/generated-课程名，不覆盖 public；人教英语、大学英语、四六级和考研英语生成器的替换目录限于本课程 public 目录或仓库 tmp 下的独立目录。

完成门槛：全部文章都有真实的逐篇记录，课程校验、生成复现及页面检查通过；待审或待查源存在时完整检查必须失败，汇总应明确报告剩余项。
