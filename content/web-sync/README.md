- 120 篇课程仍待来源确认；`verify:segmentation:complete` / `verify:spacing:complete` 必须继续报告未完成。

- 历史审核日志按用户要求排除。发布快照校验不代表历史事件链审核；`verify:article-review`、`verify:article-cleanup`、`verify:college-english:history` 等完整历史工具需要额外提供外部审核资料。工具回归使用独立完整夹具，并继续检查篡改/缺失证据会失败。

- 安装器文件当前缺失，下载产物检查按原规则跳过；官方下载地址与跨域处理保留。CI 工作流已配置，本地未实际执行远程 GitHub Actions，也未实际联网下载整批词汇。
- 断网仅承诺已缓存资源；不宣称所有课程或在线语音全部离线可用。自动化开发页面导航出现 Vite HMR socket 关闭日志，功能断言和截图验收均通过。
