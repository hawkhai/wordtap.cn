# 逐句跟读与选中朗读验收

日期：2026-11-09。范围：WordTap 阅读工作台及其桌面／窄屏界面。

## 功能

- 全文及选段共用原文句子编号，实际发声后才加粗当前句；暂停保留，停止、完成和失败时清除。Gateway 预加载不改变当前句，降级保留遍数和句子位置。
- Itim 使用 `.022em` 同色描边，不改变字宽、折行和行高；Charis 音标保持常规字重。
- 当前句越出安全区时以 280ms 缓动定位，兼顾正文内部与页面滚动。暂停、拖选和菜单操作时暂缓，减少动态效果时直接定位。超长句保留首行可见；内层已到起点时保留现有正文内边距。
- 桌面拖选或移动设备原生选区稳定后显示“朗读／复制”。朗读补齐首尾完整句子并播放一遍；复制精确选区原文，排除音标和句末按钮。支持反向、跨段选择、Esc、键盘焦点及复制失败恢复。
- 保留完整学习备份、当前文章导出、官方下载修复和 GitHub Issues／源码入口。

## 验证方法

`npm run verify` 覆盖发布快照、完整构建、业务回归、开源目录和响应式检查。相关定向入口为 `npm run test:sentence-reading`、`npm run test:reading-phonetics`。

`npm run verify:reading-interaction` 使用已有 Playwright 和 Chrome 对本地生产预览运行六组检查：1440×1000、390×844、360×844 的浅色／深色，覆盖原文及音标显示。通过 `WORDTAP_PLAYWRIGHT_MODULE`、`WORDTAP_TEST_URL` 和 `WORDTAP_TEST_OUTPUT` 指定外部工具、预览地址与产物目录。默认产物位于忽略目录 `tmp/reading-follow/`，不把大体积截图加入仓库。

检查精确复制、反向跨段、剪贴板失败、音标排除、菜单边界、键盘与焦点、实际发声事件才加粗、排版稳定、全文跟随、手动滚动、暂停继续、选区暂缓、减少动态效果、嵌套滚动、超长句、停止及编辑清理、页面溢出与运行异常；桌面另通过实际鼠标拖选检查不误触点词。
