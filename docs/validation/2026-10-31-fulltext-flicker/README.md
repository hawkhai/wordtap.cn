# 全文朗读切句闪烁验收

日期：2026-10-31 至 2026-11-01（Asia/Shanghai）。验收对象为本次全文朗读切句稳定性修改。

## 修改与约定

全文朗读将“首次发声前准备”和“开始后的片段缓冲”分开。开始后切句、切音频片段及进入下一遍，不再重新插入准备说明或切换按钮为“准备中”。后续缓冲超过 600ms，仅更新原有状态文字；发声、暂停、停止、完成及失败会清理计时器。服务降级保留是否已经发声的状态，旧回调不能覆盖新的播放状态。

此次只修改共享播放状态逻辑，桌面和移动端沿用原组件、cf-design / Arco 语义变量、原控件尺寸及句末图标例外。保留分句、语音参数、遍数、暂停／继续／停止、查词及数据保存流程。

## 浏览器检查与证据

使用开发页的真实桌面／移动端 Shell、共享阅读组件及播放逻辑，在每个尺寸切换后刷新，重新选择对应 Shell。临时测试入口只替换媒体来源，不改动产品组件：浏览器路径模拟语音开始／完成事件，含 100ms 普通衔接和一次 900ms 等待；Gateway 路径模拟本地 HTTP 响应，返回 1 秒静音 WAV，由原生 `HTMLAudioElement` 触发播放事件。
