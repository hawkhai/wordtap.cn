# Gateway 版本检测与安装引导（2026-11-02）

检测到旧版时，网站在文章输入区上方提示当前版本与最新版本，提供官方下载、安装说明和“已安装，重新检测”。说明下载后覆盖安装、必要时退出托盘服务，安装完成后自动检测。当前正式版本为 0.2.2，仍按既定约定保持未签名安装包。

## 行为与回归

- 读取 `/v1/status` 的实际版本，按数字及预发布版本顺序比较，避免 `0.2.10` 被错判为低于 `0.2.2`。
- 正式发布清单随网页打包作为基线；页面启动及手动重检时读取最新清单。离线、无效或过旧的在线清单不降低基线。下载仍使用原有官方固定入口。
- 未提供有效版本号的在线服务明确提示无法识别并建议升级；当前／更高版本不提示更新，离线服务继续使用原有安装引导。
- 保留原有播放与降级流程，不自动下载安装；更新提示独立于音频切句及准备事件，检测不覆盖正在播放的状态文字。
- 新增 6 项回归，覆盖版本比较、状态解析与超时清理、旧版到新版自动识别、离线／旧清单，以及连续多句时的心跳检测。

检查结果：两边 `typecheck` 和响应式检查通过；朗读测试 62 项通过。开发仓库完整构建通过（6 项 Python、112 项 Node，1064 个静态页主题检查）；公开仓库 `npm run verify` 通过（完整构建、118 项业务测试、仓库卫生与响应式检查）。
