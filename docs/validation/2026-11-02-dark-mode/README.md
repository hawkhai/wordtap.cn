# WordTap 深色模式验收

日期：2026-11-02。范围：根目录工作台及生成的课程目录、静态课文、考试入口、安装指南。工作区实现，未推送或发布。独立真题站和 PDF 阅读器专用主题不在本轮范围。

## 风格与实现

读取当前安装版 cf-design（EasyClaw 1.3.122）的主技能、Arco 主题资料、体验流程和质量底线，并核对 WordTap 官网现有页面。继承蓝色品牌、Itim 阅读字体、轻边框、原有工作台及 32/44px 控件；不新增组件库。

深色采用 #17171A 页面、#232324 表面、#2E2E30 次级表面、#F2F3F5 正文、#B4B8C0 辅助文字、#484849 边框。文字与链接使用浅蓝，实心按钮和安装步骤编号使用独立蓝底白字。选中、已学、成功、警告、错误和禁用使用语义变量；图片不反相，邮箱图片保留白底。

主站及静态页面在 head 中同步加载同一主题脚本，三档偏好保存在独立键 `wordtap-theme`，首次跟随系统。Vue 只订阅偏好，不重挂载学习视图。系统变化、同源标签页、刷新及跨页读取共用同一规则；静态页面无脚本时按系统主题显示并隐藏主题控件。脚本加入离线预缓存。

- `node tools/verify-static-design.mjs`：1,064 个静态页面、9 个分区通过，包括深色变量、主题控件和脚本相对路径。截图复核后修正安装编号颜色，定向重生成安装指南并再次通过全量静态检查。

真实 Gateway 朗读期间切换主题：音频元素身份不变、保持未暂停，播放位置持续前进，无错误事件；随后通过原停止按钮结束。点词选中及学习标记入口亦实际点击。[音频状态记录](speech-theme-result.json)、[播放截图](1440-dark-playing.png)。该记录验证切换过程连续，不声称对全文音质或完整播放进行了主观评审。
